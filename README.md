# zerobie-website

The interim website for **ZEROBiE** (formerly TOBiE) at **https://zerobie.com**, published with GitHub Pages
from the `zerobim` organisation. ZEROBiE is a product of ZERO.BIM s.r.o.; the real product website is being
built separately together with the application.

- Plain static HTML, CSS and JS. No build step, no external requests, no cookies (the consent choice is kept in
  `localStorage` under `zerobie_consent`).
- `CNAME` holds the custom domain: `zerobie.com`.
- Brand assets come from the ZEROBiE brand kit v3.0 (`assets/brand/`, `assets/icons/`, `favicon.ico`,
  `apple-touch-icon.png`, the social card `assets/icons/og-image.png`).
- Public messaging stance until release: show capabilities people already know from the market; keep the core
  idea off the public site.

## History
TOBiE was renamed ZEROBiE in September 2026 because the TOBiE name could not be trademarked. The old domain
`tobie.io` redirects here (see the `tobie-io-redirect` folder that ships alongside this repository).
